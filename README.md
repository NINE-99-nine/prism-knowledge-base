# Prism · 棱镜

> 本地多模态知识库 —— **用一句话，凭感觉找到任何东西。**
>
> 图片、视频、音频、文本都在**同一个向量空间**里，所以「文字搜视频」「图搜音频」「视频搜文本」全都成立。

---

## 它是什么

一个**便携自包含**的本地知识库软件。

- **索引留库，文件留原处** —— 数据库里只存「路径 + 向量 + 元数据」，**你的原文件一个字节都不动**
- **多模态统一检索** —— 文本、图片、视频、音频由同一个嵌入模型编码到同一空间，跨模态互搜天然成立
- **凭感觉找** —— 不用记文件名、不用记目录，用自然语言描述就行
- **虚拟文件** —— 手里还没成文件的东西（一个点子、一组参考素材、一整个项目），也能作为「一条」建进库，照样能被搜到
- **依赖极少** —— Python 标准库 + numpy；再加一个可选的 pywebview 换来原生窗口
- **一切都在这个文件夹里** —— 代码、前端、数据库，不往别处写

---

## 底层：基于 llama.cpp 的 EmbeddingGemma-2

Prism 自己不跑模型。它把内容发给一个**本地 OpenAI 兼容的嵌入服务**，那个服务由 **llama.cpp** 承载 **EmbeddingGemma-2**（Google 的 300M 多模态嵌入模型）。

```
你的文件 ──► Prism ──► llama.cpp (llama-server, 端口 8084) ──► 768 维向量 ──► SQLite
```

加载两样东西：

| 组件 | 文件 | 作用 |
|---|---|---|
| 主模型 | `embeddinggemma-2-BF16.gguf` | 270M，负责文本 |
| 多模态编码器 | `mmproj-embeddinggemma-2-Q8_0.gguf` | 170M 视觉 + 300M 音频 |

**两个都要下** —— 只下主模型的话，图片/视频/音频指数都不可用。

启动脚本与详细说明见 [`llamacpp-server/`](llamacpp-server/)，模型可从 Hugging Face 搜 `embeddinggemma-2 gguf` 获取。

**为什么值得这么搭**：纯本地、离线、数据不出机器；整个模型约 1 GB，普通显卡甚至 CPU 都能跑；而且**四种模态进同一个空间**这件事，是跨模态检索能成立的根本原因。

## 功能

| 功能 | 说明 |
|---|---|
| **多模态导入** | 拖入文件夹即可，支持图片 / 视频 / 音频 / 文本与代码；递归扫描、增量导入（按 path+mtime+size 指纹判断是否需要重新嵌入） |
| **导入格式筛选** | 选中文件夹后可以勾选只导入哪几类后缀，不必整个目录照单全收 |
| **三种检索模式** | **混合**（关键词命中置顶 + 语义补足，推荐）／**语义**（纯向量，按意思找）／**关键词**（朴素子串，适合搜确切名字、后缀、你记得的一句原话） |
| **跨模态互搜** | 文字搜视频、图搜音频、视频搜图片……因为都在一个空间里 |
| **拖入检索** | 把任意文件**直接拖进搜索框**，用它去库里找相似内容（或点 📎 选文件） |
| **拖入入库** | 把文件拖进**窗口**即入库 —— 需要原生桌面窗口（见下），因为浏览器出于安全不允许网页读取拖入文件的真实路径 |
| **按文件折叠** | 一个长文件被切成多段时，命中结果合并成一条并标注「命中 N 处」，不会让同一个文件占满结果位 |
| **找相似的** | 针对**文件级**比较：一个文件可能有几十个片段，只要有一处很像就算像（取最高分而不是平均，免得被不相关的片段稀释） |
| **近似重复检测** | 两两相似度超阈值即配对，并排预览对比；大库有开销护栏，不会把界面拖死 |
| **标签** | 给条目打标签、按标签筛（多选 = 同时满足）；标签本身也参与关键词检索 |
| **虚拟文件** | 见下方专节 —— 把「还没有实体文件的资料」也做成可检索的一条 |
| **失效索引管理** | 外接盘/网络盘临时没挂上时可以查看失效条目、重新扫描、或手动移除（**只动数据库，绝不碰磁盘**） |
| **桌面窗口** | 原生窗口（WebView2），标题栏跟随界面主题；没装 pywebview 时自动改用系统浏览器 |
| **夜间模式** | 跟随系统 / 日间 / 夜间，选择会被记住 |
| **前进 / 后退** | 检索历史可以像浏览器一样来回翻（`Alt+←` / `Alt+→`） |
| **网页界面** | 零构建，单页应用；图片预览、音频/视频播放器（支持拖动进度条） |

### 虚拟文件是什么

有些东西**还不是一个文件**，但你想让它能被搜到：

- 一个还没落笔的点子
- 一组散落各处的参考图 / 素材
- 一整个项目、一部剧集（关联几十集视频）

「虚拟文件」就是给这类情况做的条目。它由几部分组成：

| 部分 | 走哪种检索 |
|---|---|
| **标题** | 关键词 |
| **描述** | 语义（文本向量） |
| **配图 / 音频 / 视频** | 各自模态的向量 |

关键在于：**这些部分被视为同一个文件的片段**，所以「按文件」检索能认出它、标签能打、找相似的也能把它当一个整体比。

**媒体只存索引，不复制** —— 配图、音视频、关联的本地文件都只记路径，原文件留在原处。

关联项还支持**绑定文件夹**，所以把整个本地项目挂进来是可行的。

## 实测数据

以下都是在本机真实跑出来的结果，不是估算。

### 语义检索（用自然语言找代码）

拿 **28 个真实代码文件**建库，用 12 条**只描述功能、不含任何标识符**的中文查询去搜：

| 分块大小 | Top-1 | Top-3 |
|---|---|---|
| 500 字符 | 9/12（75%） | 10/12（83%） |
| **2048 字符** | **10/12（83%）** | **11/12（92%）** |

对照：**纯关键词模式 0/12（0%）** —— 中文查询与英文代码没有字符重合，语义检索是唯一可行路径。

### 跨模态（视频）

**15 个视频全部导入成功**，用文字搜视频 **7/7 命中**：

```
「草帽泳装少女在泳池里玩水」      → 命中对应的那段视频 ✅
「少女躺在巨大的钟表齿轮中间」    → 命中 ✅
「巨大的蓝色海洋生物飞过哥特废墟」→ 命中 ✅
「下雨的夜晚，窗外透着蓝色冷光」  → 命中 ✅
```

**以图搜视频**：拿某段视频中的一帧去搜库，**它自己的视频排第一，相似度 0.948**。

### 虚拟文件也能被正常找到

建了一条只写了**三段中文描述**的虚拟文件（标题 / 详细描述 / 简介，都是自然语言），四种模态各留了一块。然后用一句它**没出现过**的话去搜：

```
「太空科幻，士官长，星环，宇宙战争」  → 命中该虚拟文件，相似度 0.851 ✅
```

### 拖拽文件检索（任意模态互搜）

| 拖入的东西 | 结果 | 耗时 |
|---|---|---|
| 音频（9.45 MB 长曲） | **1.000** 命中自己 | 1.3 s |
| 视频（2.67 MB） | **1.000** 命中自己 | 1.5 s |
| 代码文件 | **0.998** 命中自己 | 0.1 s |
| 图片 | 0.880 命中相似图 | 0.1 s |

### 检索不写盘

连续跑 **60 次检索**（三种模式轮换），前后对比数据目录下**每个文件的字节数与修改时间**：**完全没变**。

查询向量全程只存在于内存里 —— 不落盘、不入库、不留历史。

## 使用场景

- **素材库找图** —— 几万张图和视频，忘了文件名，一句「雨天城市的夜景」就能捞出来
- **音乐库找歌** —— 记得旋律想不起歌名？用一段音频去搜
- **视频素材检索** —— 项目素材堆成山，用文字描述画面找片段；也可以拿参考图直接搜
- **代码库语义检索** —— 不记得函数叫什么，描述它「在干嘛」就能定位到文件
- **文档/笔记库** —— 用意思找，而不是用关键词撞
- **跨模态** —— 拿一张参考图，找到风格相近的视频和音乐
- **项目管理** —— 用虚拟文件把散在多个盘的项目、剧集、素材组挂成一条，描述写清楚，以后靠描述就能找到

## 环境要求

- **Windows**（Linux / macOS 也可，bat 脚本换成对应命令即可）
- **Python 3.10+**（只用于创建独立环境，之后不再依赖系统 Python）
- **llama.cpp + EmbeddingGemma-2**（见上）
- **ffmpeg（可选）** —— **只有音频切段和视频抽帧需要它**
- **pywebview（可选）** —— 装了才有原生桌面窗口；不装自动用系统浏览器

> ⚠️ **关于 ffmpeg**：`安装.bat` **不装 ffmpeg**。
> **不装它也能用** —— 图片和文本的导入、检索完全不受影响；
> 只有音频/视频入库需要它。要处理音视频就自行下载 ffmpeg（把 `ffmpeg.exe` 放进 PATH 即可，
> 或在界面「设置」里手动填路径），Prism 会自动探测。

> ⚠️ **关于 pywebview**：`安装.bat` 会**尽力**帮你装上它，装失败也不影响使用。
> 有它 → 原生窗口，**可以把文件直接拖进窗口入库**；
> 没它 → 用系统浏览器打开界面，一切功能照旧，只是拖入只能检索、不能入库。

## 安装与启动

```
1. 双击 安装.bat      创建独立环境 .venv 并装依赖（numpy 必需 / pywebview 可选）
2. 启动嵌入服务       见 llamacpp-server/，保持窗口开着
3. 双击 prism.bat     启动 Prism 并自动打开窗口
```

停止：关掉窗口，或双击 `stop.bat`。只想开界面：双击 `打开界面.bat`。

> `prism.bat` 重复双击是安全的 —— 服务已在跑时它不会开第二个、也不会堆浏览器标签。

### 基本流程

1. 左侧 **＋** 新建一个库
2. **选择文件夹**（或把文件拖进去）→ 选中要索引的目录
3. 等进度条跑完（图片约 1.5 秒/张，文本约 0.1 秒/段，视频约 1~2 秒/个）
4. 在检索框里用**一句话描述**，或者**直接把文件拖进去**

### 想给桌面做个快捷方式

发布包里**不带快捷方式** —— 因为 `.lnk` 里写的是绝对路径，在别人机器上必然失效。

自己做一个更省事：右键 `prism.bat` → **发送到 → 桌面快捷方式**，再右键改个名字和图标即可。

## 配置

界面上点「⚙ 设置」可改：

| 项 | 默认 | 说明 |
|---|---|---|
| `embed_api` | `http://127.0.0.1:8084/v1/embeddings` | 嵌入服务地址（OpenAI 兼容） |
| `embed_model` | `embeddinggemma-2` | 请求体里的 model 字段 |
| `embed_dim` | `768` | 向量维度，须与模型实际输出一致 |
| `embed_timeout` | `180` | 单次请求超时（秒） |
| `ffmpeg_path` | 自动探测 | 音频/视频处理用，可手动指定 |
| `audio_chunk_seconds` | `60` | 音频每段时长（见下方 token 预算） |

程序常量在 `server/config.py`：

| 常量 | 默认 | 说明 |
|---|---|---|
| `CHUNK_SIZE` | `2048` | 文本分块字符数（实测此值检索效果优于 500） |
| `CHUNK_OVERLAP` | `200` | 段间重叠 |
| `VIDEO_FRAMES` | `16` | 每个视频抽几帧 |
| `VIDEO_FRAME_WIDTH` | `512` | 抽帧长边上限 |
| `TMP_MAX_AGE_SEC` | `7200` | 临时文件超时清理（2 小时） |
| `TMP_MAX_BYTES` | `500 MB` | 临时文件容量上限 |

### 关于 token 预算

EmbeddingGemma-2 的上下文上限是 **2048 token**，上面那些默认值都是照这个预算定的：

| 输入类型 | 实测占用 |
|---|---|
| 图像（长边 ≤512px） | **80 token/帧** → 16 帧 ≈ 1280 |
| 音频 | **约 65~70 token/秒** → 30 秒 ≈ 2000（刚好卡线） |
| 中文文本 | 约 1 token / 1.2 字 → 2048 字符 ≈ 1700 |

⚠️ **音频这一段特别容易踩线**：实测 **60 秒的段落会被服务端拒收**
（`input (~4053 tokens) is too large, current batch size: 2048`），
而 **20 秒左右是安全区**。所以入库长音频时，建议把 `audio_chunk_seconds` 调到 **20**；
即使没调，Prism 也会在段落被拒时**自动对半重切**再试（最多退到 5 秒），不会整条失败。

改这些参数前建议先算一遍，别让单次输入越过 2048。

## 设计取向

- **不碰你的文件**。索引只记路径和向量；删除索引不删文件；「移除失效」只清数据库。
- **不写你没要求的盘**。运行时数据全部落在 `data/`；临时文件（音频切段、视频抽帧）用完即删，另有 2 小时/500 MB 两条兜底清理线。
- **空间会自己还回来**。SQLite 开了 `auto_vacuum = INCREMENTAL`，删库、清失效索引之后空间自动回收，不会留下看不见的空洞。
- **可诊断**。检索结果带相似度分数；想确认「为什么搜到它」，看分数和文本预览就行。
- **界面克制**。护栏提示不弹对话框，就是一行字加一个小按钮。
