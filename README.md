# Prism · 棱镜

> 本地多模态知识库 —— 用一句话，凭感觉找到任何东西。
> 图片、文本、音频在**同一个向量空间**里，用同一个查询就能一起搜出来。

---

## 它是什么

一个**便携自包含**的本地知识库软件：

- **索引留库，文件留原处** —— 数据库里只存「路径 + 向量 + 元数据」，你的原文件一个字节都不动
- **多模态统一检索** —— 文本、图片、音频都由同一个嵌入模型（EmbeddingGemma-2，768 维）编码，所以「文字查图片」「图片查图片」都成立
- **凭感觉找** —— 不用记文件名、不用记目录，用自然语言描述就行
- **零第三方依赖** —— 只用 Python 标准库 + 已装好的 numpy，不装任何包
- **全部东西都在这个文件夹里** —— 代码、前端、数据库，不往别处写

## 怎么用

### 环境（只需做一次）

Prism 自带独立 Python 环境，放在 `prism\.venv\`（约 67 MB，含 numpy）。

- 本机已经装好了，**不用管**。
- 若把整个 `prism` 文件夹拷到别的机器、或 `.venv` 丢失，**双击 `安装.bat`** 重建即可。
- `安装.bat` 重复运行是安全的：**依赖已经装好就跳过那一段，直接问 ffmpeg；连 ffmpeg 都有了就几秒钟自己关掉**。首次运行时会问要不要连 **ffmpeg** 一起装（10 秒内不选 = 只装必需的 numpy / pywebview）。

### ffmpeg（音频、视频、AVIF/TIFF 图片要用）

没有 ffmpeg 时：文本、png/jpg/webp/gif 图片照常；**音频、视频、AVIF/TIFF 图片导不进去**。

- 查找顺序：设置里手填的路径 → `PRISM_FFMPEG` 环境变量 → 本项目的 `.venv\ffmpeg\bin\ffmpeg.exe`
  → `data\bin\` → 系统 PATH → WinGet / Scoop / Chocolatey → `C:\ffmpeg` 等常见位置。
  本机早就装过 ffmpeg 的，会自动用上，不必再装一份。
- 找不到时：**设置 → ffmpeg 那一栏 → 「部署到本项目虚拟环境」**，自动下载到
  `.venv\ffmpeg\bin\ffmpeg.exe`。带进度；也可以自己在上面手填路径。
- 下载策略（不假设你有梯子）：先把几个源各试 256 KB **测速**，挑最快的下，其余排队当备用；
  中途断了按断点**续传**（一个源最多续 5 次才换源），不会因为一次抖动就白下；
  直连源全不通时自动走 **pip 镜像**（清华 → 官方）里的 `imageio-ffmpeg`，掏它自带的 ffmpeg.exe（约 30 MB）。
- 部署位置刻意放在 `.venv` 里：属于这套自包含软件自己的东西，`.gitignore` 已忽略，不进仓库、不撑大发布包。
- 装好之后，`ffmpeg -version` 能出版本号才算成功（脚本就是这么验证的，不是"文件存在"就算）。
- 离线/内网：设 `PRISM_FFMPEG_URL` 指向自己的 ffmpeg zip（里面要有 `bin/ffmpeg.exe`）即可。
- 导入前会预检：这批里若有音频/视频/AVIF·TIFF 而 ffmpeg 缺失，会**当场拦下并指路**，不会让它们一个个失败。

### 启动

双击 **`prism.bat`** —— 会弹出一个控制台窗口（服务），并自动打开浏览器。

- **重复双击是安全的**：如果服务已经在跑，它既不开第二个服务、**也不会开新的浏览器标签**（只把地址显示出来，6 秒后自己关）
- 窗口标题是 `Prism - 棱镜`
- 只想打开界面（不启动服务）：双击 **`打开界面.bat`**

### 停止

关掉那个控制台窗口，或双击 **`stop.bat`**。

服务停止后，那个窗口会**自己关掉**（提示 15 秒后自动关闭，按任意键可立即关），不需要你再点一下。

### 前置条件

需要本地嵌入服务在跑（默认 `127.0.0.1:8084`）。若页面右上角显示「嵌入服务未连接」，先启动它
（任何提供 `POST /v1/embeddings` 的服务都行，比如 llama.cpp 的 embedding server）：

```
# 例：llama.cpp 的 server 加载 EmbeddingGemma-2（按自己的路径与模型文件名改）
llama-server.exe -m embeddinggemma-2-q8_0.gguf --embeddings --port 8084
```

### 基本流程

1. 左侧 **＋** 新建一个库（比如「我的素材」）
2. 点 **选择文件夹** → 弹原生对话框 → 选中要索引的目录
3. 等进度条跑完（图片约 1.5 秒/张，文本约 0.1 秒/段）
4. 在检索框里用**一句话描述**你要找的东西

> 浏览器出于安全限制拿不到「拖入文件」的真实路径，所以拖拽会转成原生选择框 —— 少一次点击的差别。

## 界面

瑞士风 + 柔和化：严格网格、无衬线字体、灰阶为主 + 单一莫兰迪强调色、细线分隔、几乎不用圆角与阴影。

- **检索** —— 主界面，输入描述 → 结果按类型自适应呈现（图片缩略图 / 文本高亮片段 / 内嵌音频播放器）
  - **检索模式三档**（默认「混合」，用 `localStorage` 记住上次的选择）
    - **混合**：关键词命中置顶 + 语义补足 —— 搜名字时关键词那路兜住，搜概念时全是语义排序
    - **语义**：纯向量，按「意思像不像」找
    - **关键词**：朴素子串匹配，找确切的名字 / 后缀 / 你记得的一句原话
  - **「按文件」开关**（默认开）：同一个文件的多段命中折叠成一条，卡片显示「命中 N 处」，可展开看分数最高的前几段
    - 为什么：一个 1 万字的文件有 20 段，不折叠的话一个文件会占掉好几个结果位
    - 关掉则回到「一段一条」的原始视图
  - **「查看全文」**：文本类结果可直接打开完整原文（不是片段），自动识别 UTF-8 / UTF-16 / GBK 编码，超 4 MB 会截断提示
- **浏览** —— 按库列出全部条目，可检查源文件是否还在
- **近似重复** —— 两两相似度 ≥ 阈值（默认 0.97）的配对，用来清理重复素材
  - 默认**排除同一文件的段落互比**、**按文件对去重**（只留最高分）
  - 点开任一条可**并排预览**两侧（图片显示图 / 音频两个播放器 / 文本前两段），并可**定位**或**打开**各自对应的文件
  - ⚠️ 音频的百分比区分度差（模型音频塔为语音/环境音训练）—— **请用耳朵确认**，别只看数字
- **失效索引** —— 库列表上出现橙色的「⚠ 失效 N」时可点开：列出原文件已找不到的条目，可**重新扫描**或**移除失效**（只删数据库记录，绝不碰磁盘）
- **条目详情** —— 点任意结果打开右侧抽屉：预览、标签、在资源管理器中定位、跨库移动、找相似
- **音频播放互斥** —— 播放新的一条时自动暂停其余所有播放器

### 为什么一个库一个文件

- **删库 = 删文件**：空间立刻 100% 回到磁盘，不需要任何"压缩"动作
- **压实只影响出事的那个库**：不会为一个小库的碎片去重写整个大库
- 库与库不再争同一个写锁

### 空间回收（不用你点任何按钮）

建库时严格按 `auto_vacuum → journal_mode → 建表` 的顺序打开「即时回收」——
顺序反了这句开关会被数据库静默忽略（不报错），库就一辈子只增不减，这是旧版的病根。

- 删除腾出来的**整页**立刻还给文件系统，写量 ∝ 被删掉的数据量，与库总大小无关
- 页内碎片（一页里只剩两三条、整页空不出来）由后台线程处理：
  删除量 / 现存行数 ≥ 30% 且没有导入在跑时，才 `VACUUM INTO` 新文件并原子替换
  （只读源库、不阻塞读写；实测 8 MB 库 28 ms）
- 每轮保洁顺手把草稿（`-wal`）合并回主文件并截断，不再常驻几 MB
- 没人用的标签行随着删除自动清掉

## 设计取舍

| 决定 | 理由 |
|---|---|
| SQLite 存元数据与向量 | 单文件好备份；支持增量更新（改一条不用重写全部） |
| numpy 算相似度 | 万级毫秒级；十万级 177ms；再大就换 sqlite-vec（扩展加载已验证可用） |
| 文本切段（约 500 字，带重叠） | 能定位到「第几段说了什么」，检索质量远高于整文件一个向量 |
| 指纹 = 路径+mtime+大小 | 重复导入自动跳过；文件变了自动重新嵌入 |
| 源文件缺失时标记 `missing` | 绝不自动删库条目，也绝不碰源文件 |
| 零第三方依赖 | 满足「便携自包含」：拷贝整个文件夹到别的机器仍能跑 |

## API（给 AI 用）

服务在 `http://127.0.0.1:8848`。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 服务 + 嵌入服务状态 + 统计 |
| GET | `/api/stats` | 统计 |
| GET | `/api/libraries` | 库列表（带 `file_count` / `missing_count`） |
| POST | `/api/libraries` | 建库 `{name, description, primary_type}` |
| POST | `/api/libraries/<id>` | 改库 |
| DELETE | `/api/libraries/<id>` | 删库（含索引，源文件不动） |
| GET | `/api/libraries/<id>/items` | 库内条目（分页 `limit`/`offset`） |
| GET | `/api/libraries/<id>/files` | 库内文件（按文件聚合的视图） |
| GET | `/api/libraries/<id>/files/chunks?path=` | 某文件的全部段落 |
| POST | `/api/libraries/<id>/rescan` | 扫描：把源文件已找不到的标为失效 |
| GET | `/api/libraries/<id>/missing` | 列出**失效条目**（原文件已找不到） |
| POST | `/api/libraries/<id>/purge-missing` | **移除失效索引**（只删数据库记录，绝不碰磁盘） |
| POST | `/api/import` | 导入 `{library_id, paths[], recursive}` → `job_id` |
| GET | `/api/jobs` · `/api/jobs/<job_id>` | 任务列表 / 进度（total / done / failed / skipped） |
| POST | `/api/jobs/<id>/cancel` · `/api/jobs/<id>/retry` | 取消 / 重试失败项 |
| POST | `/api/search` | 检索 `{library_id, query, top_k, modality, group, mode}` —— 见下 |
| POST | `/api/search/image` | 以图搜库 `{library_id, path}` |
| POST | `/api/similar` | 找相似 `{library_id, item_id}` |
| POST | `/api/duplicates` | 近似重复 `{library_id, threshold, limit, same_file}` |
| GET | `/api/item/<id>` | 条目详情（含标签） |
| DELETE | `/api/items/<id>` | 移除索引（不删源文件） |
| POST | `/api/items/move` · `/api/items/copy` | 跨库移动 / 复制 |
| POST | `/api/items/<id>/tags` · GET `/api/tags` | 标签 |
| GET/POST/PATCH | `/api/settings` | 设置；`/api/settings/test` 测试连接、`/reset` 恢复默认 |
| POST | `/api/pick` | 弹原生选择框（浏览器拿不到真实路径） |
| POST | `/api/reveal` | 在资源管理器里定位（**仅限已索引文件**） |
| POST | `/api/open` | 用系统默认程序打开（**仅限已索引文件**） |
| GET | `/api/file?path=...` | 源文件代转发（仅限已索引的文件；支持 `Range` / 206 / `HEAD`） |

### 检索的三个模式（`/api/search` 的 `mode`）

| mode | 做什么 | 什么时候用 |
|---|---|---|
| **`mixed`**（**默认**） | 关键词命中**置顶** + 语义补足，按文件去重 | 不确定就用它 |
| `semantic` | 纯向量，按「意思像不像」打分 | 找一个**概念** |
| `keyword` | 朴素子串匹配 `path` / `chunk_text`，按命中位置排序（文件名 > 路径 > 正文） | 找**确切的名字 / 后缀 / 原话** |

**为什么要 `keyword`**：向量模型对「一个具体名字」天然弱（名字本身没什么语义）。实测搜确切歌名，正确答案只排第三；切到 `keyword` 或 `mixed` 立刻第一。前端也有三档切换，**默认混合并记住上次选择**。

`group:true` 时把同一文件的多段命中折叠成一条（带 `hits` 命中数与 `chunks` 明细）。

**注意**：`POST` 请求体必须是 **UTF-8 编码的 JSON**（中文不要用 Windows 命令行直接传）。

## 已知边界

- **音频**：按时长切段后逐段嵌入，**段长默认 30 秒**（≈2000 token，避开 4096 上下文的悬崖）；遇到 token 溢出会自动对半再切重试。切出的临时段落在 `data\tmp\`，用完即删 + 启动清理（超 2 小时 / 超 500 MB 两条线）。时长探测失败（`moov atom not found`）说明**文件本身损坏**，无法索引
- **音频相似度区分度差**（EmbeddingGemma 音频塔为语音/环境音训练）—— 判断是否重复请**用耳朵**，别只看百分比
- **大库做近似重复是 O(n²)**：16,684 段需要约 1.1 GB 矩阵、50 秒以上。大库请调高阈值或加 `limit`
- **导入是串行的**：嵌入服务单实例，并发会互相抢；430 张图约 12 分钟
- **拖拽**：浏览器拿不到真实路径，会自动转为原生选择框
- **自动聚类 / MCP / RAG 问答**：预留接口，二期再做
