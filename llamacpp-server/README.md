# 嵌入服务（llama.cpp）

Prism 不自己跑模型 —— 它把「文本 / 图片 / 视频 / 音频」都发给一个
**本地 OpenAI 兼容的嵌入服务**，那个服务由 **llama.cpp** 承载
**EmbeddingGemma-2**（Google 的 300M 多模态嵌入模型）。

## 为什么用 llama.cpp

- **四模态统一空间**：主模型 + 多模态编码器（mmproj）一起加载后，
  文本、图像、视频、音频都被编码到**同一个 768 维空间** ——
  这是「用一句话搜视频」「用一张图搜音频」能成立的前提。
- **纯本地、离线**：不联网、不调云端 API，数据不出机器。
- **轻量**：整模型约 1 GB，普通显卡甚至纯 CPU 都能跑。

## 启动

1. 装好 llama.cpp（拿到 `llama-server.exe`）
2. 下载两个 GGUF：
   - 主模型 `embeddinggemma-2-BF16.gguf`（约 530 MB）
   - 多模态编码器 `mmproj-embeddinggemma-2-Q8_0.gguf`（约 530 MB）
     —— **这个不能少**，图片/视频/音频全靠它；只下主模型的话就只有文本能用
3. 编辑 `start-embedding-server.bat`，把三个路径改成你自己的
4. 双击运行

看到 `listening on http://0.0.0.0:8084` 就成了。保持窗口开着。

## 关键参数说明

| 参数 | 值 | 说明 |
|---|---|---|
| `-c` / `--batch-size` | 2048 | **模型官方上限就是 2048 token**，设大无益 |
| `--ubatch-size` | 2048 | 物理批大小 |
| `--embeddings` | — | 开启嵌入模式 |
| `--pooling mean` | — | 平均池化，EmbeddingGemma 要求 |
| `-ngl 99` | — | 尽可能多的层放显卡；纯 CPU 可改 0 |

## 实测的 token 占用（估算上下文用量时参考）

| 输入 | 占用 |
|---|---|
| 图像（长边 ≤512px） | **80 token/帧** |
| 音频 | **约 25 token/秒** |
| 中文文本 | 约 1 token / 1.2 字 |

所以：**视频抽 16 帧 ≈ 1280 token**、**音频切 60 秒 ≈ 1500 token**，
都在 2048 以内 —— Prism 里的这些默认值就是照这个预算定的。

## 换了别的模型？

Prism 的嵌入服务地址、模型名、向量维度都可以在界面「设置」里改，
只要对方是 OpenAI 兼容的 `/v1/embeddings` 端点就行。
但**必须是把多模态编码到同一空间的模型**，否则「跨模态互搜」不成立。
